# 🚀 After Office Cypress Automation Learning

Repositori ini digunakan untuk mencatat, melacak *progress*, dan menyimpan seluruh materi serta latihan praktis dalam program pembelajaran **After Office: Cypress Automation Testing**.

---

## 🛠️ Prasyarat (Prerequisites)

Sebelum menjalankan proyek ini di komputer lokal, pastikan Anda telah menginstal:

- [Node.js](https://nodejs.org/) (Versi LTS direkomendasikan, contoh: v18+)
- [npm](https://www.npmjs.com/) (Biasanya otomatis terinstal bersama Node.js)
- [Git](https://git-scm.com/)
